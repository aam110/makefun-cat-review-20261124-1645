[Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).

## The review

> One star. My human dunked me in water, called it love, and now I smell of lavender and betrayal.

## How it works

`main.ts` writes the review as a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
It is deterministic: the same constant string, byte-identical on every run.

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```
